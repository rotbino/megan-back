# پایتون — زیرپروژه‌های مستقل

ابزارهای پایتونی که مستقل از سرویس NestJS کار می‌کنند و فقط از طریق دیتابیس/استوریج با بقیهٔ پروژه حرف می‌زنند. هر ابزار یک پوشهٔ مستقل با `requirements.txt` و راهنمای خودش است تا بعداً ابزارهای جدید بدون قاطی‌شدن اضافه شوند.

## ساختار

```
python/
└── image-editing/     ← حذف واترمارک پاسکال از تصاویر گالری (تشخیص مختصات + حذف با تمپلیت آلفا)
```

## قواعد

- هیچ وابستگی‌ای به `node_modules` پروژهٔ اصلی ندارند؛ محیط مجازی خودشان را دارند:
  `python3 -m venv .venv && source .venv/bin/activate && pip install -r <tool>/requirements.txt`
- متغیرهای محیطی را از `megan-back/.env` می‌خوانند (یا `.env` داخل خود پوشهٔ ابزار).
- خروجی‌ها و وضعیت اجرا فقط داخل پوشهٔ `output/` هر ابزار (gitignore شده).

راهنمای کامل ابزار حذف واترمارک: [image-editing/README.md](image-editing/README.md)
